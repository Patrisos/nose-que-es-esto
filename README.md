## Para Principiantes / For Beginners

### ¿Qué es Git?
Git es un sistema de control de versiones que te permite:
- Guardar el historial de cambios de tu código
- Trabajar en equipo sin sobrescribir el trabajo de otros
- Volver a versiones anteriores si algo sale mal

### ¿Qué es GitHub?
GitHub es una plataforma web que usa Git y te permite:
- Almacenar tus proyectos en la nube
- Colaborar con otros desarrolladores
- Mostrar tu trabajo al mundo

### What is Git?
Git is a version control system that allows you to:
- Save the history of changes to your code
- Work in teams without overwriting others' work
- Go back to previous versions if something goes wrong

### What is GitHub?
GitHub is a web platform that uses Git and allows you to:
- Store your projects in the cloud
- Collaborate with other developers
- Show your work to the world

## Primeros Pasos / Getting Started

### 1. Crea una cuenta / Create an account
Si aún no tienes una cuenta de GitHub, créala en [github.com](https://github.com)

If you don't have a GitHub account yet, create one at [github.com](https://github.com)

### 2. Instala Git / Install Git
- **Windows**: Descarga desde [git-scm.com](https://git-scm.com)
- **Mac**: Usa `brew install git` o descarga desde git-scm.com
- **Linux**: Usa `sudo apt-get install git` (Ubuntu/Debian) o el gestor de paquetes de tu distribución

### 3. Configura Git / Configure Git
```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"
```

### 4. Comandos Básicos / Basic Commands

#### Clonar un repositorio / Clone a repository
```bash
git clone https://github.com/usuario/repositorio.git
```

#### Ver el estado / Check status
```bash
git status
```

#### Agregar cambios / Stage changes
```bash
git add archivo.txt        # Agregar un archivo específico
git add .                  # Agregar todos los cambios
```

#### Hacer commit / Commit changes
```bash
git commit -m "Descripción de los cambios"
```

#### Subir cambios / Push changes
```bash
git push origin main
```

#### Actualizar tu copia local / Update your local copy
```bash
git pull origin main
```
