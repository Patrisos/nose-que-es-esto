# nose-que-es-esto

## Cómo subir fotos

Podés agregar fotos al repositorio subiéndolas a la carpeta [`images/`](images/).

### Desde la web de GitHub

1. Andá a la carpeta [`images/`](images/).
2. Hacé clic en **Add file** → **Upload files**.
3. Arrastrá o seleccioná las fotos que quieras subir.
4. Hacé clic en **Commit changes**.

### Mostrar una foto en el README

Una vez subida la foto, podés mostrarla acá usando esta sintaxis Markdown:

```markdown
![Descripción de la foto](images/nombre-de-la-foto.jpg)
```
